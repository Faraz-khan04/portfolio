Every request you make crosses this planet in milliseconds, through routers, DNS lookups and handshakes most people never see. That hidden path is what I study.

0x04 / On the wire

One request, four envelopes.

Before a single byte reaches the cable, your browser's request gets wrapped by each layer of the network stack. Scroll to watch one HTTP request get packed for the wire.

  1. L7ApplicationThe request itself
  2. L4TransportTCP adds ports and ordering
  3. L3NetworkIP adds where it is going
  4. L2Data linkEthernet adds the next hop and a checksum
